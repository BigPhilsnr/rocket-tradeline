Checkout Process
API
checkout_cart(cart_id, address_id)

File: api/cart.py

VALIDATIONS
Pre-Checkout Checks
  • ✓ User account is enabled
  • ✓ Customer has_signed_agreement = 1
  • ✓ Customer is_questionnaire_filled = 1
  • ✓ Cart is not empty
  • ✓ Payment mode selected
  • ✓ validate_cart_slots() - Real-time availability
⚠️ Slot Validation Logic:
  • Queries all Client Tradelines with status: Active, Inactive, Pending AU, Refund Requested
  • Calculates: remaining_spots = max_spots - SUM(active quantities)
  • Returns 409 Conflict if slots exceeded
UPDATES
Cart Status Change
  • status: Active → Checked Out
  • payment_status: "Pending"
  • payment_address: linked address

Client Tradeline Creation
CREATES
create_client_tradelines_from_payment()

File: doctype/client_tradelines/client_tradelines.py

Trigger: Payment Request approval

Logic: FOR EACH cart_item IN cart.items

CREATES
Client Tradelines Doctype
  • title: "CT-{customer}-{tradeline}-{timestamp}"
  • customer: from cart
  • customer_name: customer.customer_name
  • cart: payment_request.cart_id
  • payment_request: payment_request.name
  • tradeline: cart_item.tradeline
  • tradeline_name: "{bank} - ${credit_limit}"
  • quantity: cart_item.quantity
  • unit_price: cart_item.rate
  • total_amount: cart_item.amount
  • status: Pending AU
  • created_date: now_datetime()
🔄 Auto-Triggered Hooks:
  • before_insert: Sets default values, names
  • after_insert: recalculate_tradeline_remaining_spots()
  • on_update: handle_status_change()
📊 Spot Recalculation:
  • Updates parent Tradeline document
  • purchased_spots = SUM(all active client quantities)
  • remaining_spots = max_spots - purchased_spots
  • Prevents overbooking in real-time

📋 Email Context Data:

  • 1️⃣ Cardholder logs into bank website
  • 2️⃣ Adds AU with customer name, DOB, SSN last 4

↓
ADMIN ACTION
Confirm AU Assignment
  • Admin receives proof from cardholder
  • Uploads 📎 proof_of_au_assignment to Client Tradelines

🔔 Reminder System:

Scheduled task sends AU Assignment Reminder email if status remains "Pending AU" for extended period
